# Cricket Analytics

Cricket statistics and analysis repository organized by gender categories. Contains player performance data, match records, team statistics, and comprehensive analytical notebooks for both men's and women's cricket.

## 📁 Folder Structure

```
cricket/
├── README.md              # This file
├── mens/                  # Men's cricket data and analysis
│   ├── README.md
│   ├── [data_files]
│   └── [notebooks]
└── womens/                # Women's cricket data and analysis
    ├── README.md
    ├── [data_files]
    └── [notebooks]
```

## 👨‍🏫 Men's Cricket

Statistical data, analysis notebooks, and insights for men's cricket across various formats and leagues.

**Available Data:**
- International match records (Test, ODI, T20I)
- Domestic league statistics
- Player performance metrics
- Career statistics
- Season-by-season analysis

For detailed information, see [mens/README.md](mens/README.md)

## 👩‍🏫 Women's Cricket

Statistical data, analysis notebooks, and insights for women's cricket across various formats and leagues.

**Available Data:**
- International match records (Test, ODI, T20I)
- Women's domestic league statistics
- Player performance metrics
- Career statistics
- Season-by-season analysis

For detailed information, see [womens/README.md](womens/README.md)

## 📊 Data Categories

Each subcategory (men's/women's) may contain further organization:

- **International** - Test, ODI, and T20I international matches
- **Domestic** - National domestic league data
- **Players** - Individual player statistics and records
- **Teams** - Team performance metrics and rankings
- **Formats** - Format-specific analysis (Test, ODI, T20, etc.)

## 📝 Common Data Files

- Player statistics (batting and bowling averages, strike rates, etc.)
- Match records and scorecards
- Team standings and rankings
- Historical records and milestones
- Performance trends and analytics

## 🔧 How to Add Data

1. Navigate to the appropriate subfolder (mens/ or womens/)
2. Create a descriptive subfolder if needed (e.g., `international_2024`)
3. Add your raw data files
4. Create analysis notebooks as needed
5. Document everything in the subfolder README

## 📋 Data Guidelines

- **Naming Convention**: Use snake_case for file names (e.g., `ipl_2024_stats.csv`)
- **Formats**: Prefer CSV for tabular data, JSON for complex structures
- **Metadata**: Include data source, collection date, cricket format, and version
- **Documentation**: Clearly document data sources and collection methods

## 🤝 Contributing

When adding cricket data or analysis:

1. Determine if data belongs to men's or women's cricket
2. Create appropriate subfolder if needed
3. Ensure data is properly validated and cleaned
4. Document cricket format (Test, ODI, T20I, T20, etc.)
5. Include comprehensive metadata about the data
6. Add analysis notebooks with clear comments
7. Update relevant README files

## 📚 Cricket Formats Reference

- **Test Cricket**: Longest format, typically 5 days
- **ODI (One Day International)**: 50 overs per side
- **T20I (Twenty20 International)**: 20 overs per side
- **T20 (Domestic Twenty20)**: Domestic twenty-over format
- **Other**: Various domestic formats across different countries
